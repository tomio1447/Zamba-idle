Place the extracted assets from https://github.com/Levi999x/15.x-with-8.60 here.

Required files (after unzip Tibia_spr_dat.zip):
- Tibia.spr
- Tibia.dat
- (optional) items.xml, outfits.xml, mounts.xml

You can also place the full extracted folder contents here.

The game will try to load from:
- /assets/tibia-860/Tibia.spr
- /assets/tibia-860/Tibia.dat

For best compatibility, also copy:
- Tibia.otfi
- outfits.xml

After placing files, reload the game and use the "🎨 Sprites" button in the Battle panel.
